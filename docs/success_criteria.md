# 성공 기준 (실험 전 고정)

- **고정일: 2026-10-03** (5단계, 같은 날 태그 전에 주·보조 분석 교체와 사전 보강). 6단계 실행 전에 커밋하고 `criteria-locked` 태그를 단다. 결과를 본 뒤 바꾸지 않는다.
- 채점 규칙: `experiment/scoring_rules.md` / 채점기: `experiment/grader.py` / 지시문: `experiment/agent_prompt.md`
- 근거: `docs/research_plan.md` 7.5~7.7, `docs/phases.md` 5단계 확정 사항

## 용어

- **배치**: 변형 하나에 심은 결함 하나. 결함 변형 16개에 배치 24개(공개 16, 보류 8)가 있다.
- **배치-실행**: 배치 × 반복 실행. 조건마다 24 × 3 = 72개다.
- **탐지율**: 탐지된 배치-실행 / 전체 배치-실행. 반복 3회를 모두 합쳐 센다.
- **주 분석**: 결함 항목을 지목하면 탐지 (문제 종류 무관). **보조 분석**: 항목과 문제 종류(Q)를 모두 맞혀야 탐지.
- **오경보**: 결함을 심지 않은 채점 대상 항목에 대한 지적. 보고서 하나 안에서 같은 항목은 한 번만 센다.

## 주 분석을 "항목만"으로 정한 이유 (2026-10-03 변경, 실험 전)

처음에는 주 분석을 "항목 + 종류", 보조 분석을 "항목만"으로 정했다. 태그를 달기 전에 둘을 서로 바꿨다.

- 사용자 확인 결과(사전 보강 전), 핵심어 사전이 문제 종류를 인정한 비율은 다음과 같았다.
  - 점검기가 내는 문장: **16/16**
  - 사람·에이전트가 쓰는 자연스러운 표현의 올바른 지적: **19개 중 14개**
- 그래서 종류 판별은 점검기 문장을 그대로 옮기기 쉬운 (가)에 유리한 **측정 편향**을 만든다.
  같은 내용을 맞혀도 (나)는 표현 때문에 미탐지로 떨어질 수 있다.
- 항목만으로 판정하면 이 편향이 사라진다. 바꾸는 방향은 (가)에 **불리한** 쪽이다. (나)가 종류를 말하지 못해도 탐지로 인정되므로 두 조건의 차이가 작아진다.
- 자연스러운 표현 중 놓친 5개는 사전에 보강했다. 그래도 사전이 모든 표현을 덮는다고 볼 수 없으므로 종류 판별은 보조 분석에 둔다.
- 실험 결과(에이전트 보고서, 탐지 결과)는 아무것도 보지 않은 상태에서 바꿨다 (6단계 실행 전, 정답표 봉인 상태).

## H1. 스킬이 탐지율을 높이고 오경보는 적다

**기준 (주 분석으로 판정)**: 두 조건을 모두 만족하면 H1을 지지한다.
1. 탐지율 차이 (가) − (나)의 95% 신뢰구간 하한 > 0
2. 깨끗한 변형 4개 × 3회에서 (가)의 오경보가 보고서당 평균 1건 이하

**신뢰구간 계산**: 결함 변형 16개를 단위로 한 짝지은 부트스트랩.
- 두 조건이 같은 변형을 쓰므로 변형을 복원 추출로 다시 뽑고, 뽑힌 변형의 배치-실행으로 두 조건 탐지율 차이를 계산한다.
- 10,000회, 시드 20261003, 백분위 2.5%·97.5%를 쓴다.
- 한 변형 안의 결함·반복은 서로 독립이 아니므로 변형을 묶음 단위로 뽑는다.

## H2. 스킬이 보류 사례도 잡는다

**기준 (주 분석으로 판정)**: (가)의 보류 사례 탐지율 > 무작위 기대 탐지율이면 H2를 지지한다.

**무작위 기대 탐지율**: "같은 수의 경고를 무작위로 배치했을 때"의 탐지율이다.
- (가)의 보고서마다 m을 정한다. m은 그 보고서가 지목한 채점 대상 항목 수(서로 다른 항목, 결과·예측 시점은 각 1개)다.
- 그 변형의 채점 대상 항목 N개(특징·포함·제외·전처리 각 항목과 분할·결과·예측 시점·하위 집단·기준 시점) 중 m개를 무작위로 고른다.
- 이렇게 했을 때 보류 결함 항목을 하나라도 고를 확률을 정확히 계산한다(초기하 분포). 보류 배치-실행 전체에서 평균한 값이 기대 탐지율이다.
- 보조 분석의 기대치는 고른 항목마다 문제 종류 6개(Q1·Q2·Q3·Q4·Q5·Q7) 중 하나를 무작위로 붙여, 항목과 종류를 함께 맞힐 확률이다.
- 결함 항목과 같은 항목으로 인정되는 것(예: `outcome.ascertainment`에 대한 `outcome`, `cohort.subgroups`)은 모두 맞는 항목으로 센다.

**함께 보고하는 것**
- (나)의 보류 사례 탐지율과 그에 대한 같은 방식의 무작위 기대치
- 단측 정확 p값(각 배치-실행의 무작위 탐지 확률로 만든 포아송 이항 분포, 관측 탐지 수 이상일 확률). 참고용이며 판정 기준이 아니다.
- 보류 6개 전체와, 봉인 해제 뒤 조정하지 않은 보류 3개만으로 따로 계산한다(`docs/phases.md` 7단계). 정답표의 `adjustment` 칸으로 구분한다.

## 주 분석과 보조 분석의 결론이 다를 때

- H1·H2는 **주 분석으로 판정한다**. 보조 분석은 같은 기준으로 계산해 항상 함께 보고한다.
- 두 분석의 결론(기준 충족 여부)이 다르면 보조 분석 결과를 주 분석과 나란히 제시하고, 결론을 **조심해서 해석한다**.
  예: 주 분석만 기준을 넘으면 "항목은 찾았지만 문제 종류를 핵심어 사전이 알아보는 말로 하지 못했다"는 뜻이다. 에이전트의 이해 부족일 수도, 사전의 한계일 수도 있다.
  채점기는 이런 불일치를 `primary_secondary_disagree`에 기록한다.
- 결론이 다르다는 이유로 판정 기준을 바꾸지 않는다.
