# 알려진 문제

`skill-frozen` 태그 뒤에 `leakcheck/`, `skill_src/`에서 발견한 버그는 고치지 않고 여기에 적는다 (CLAUDE.md 절대 규칙 3).
각 항목: 날짜, 발견 경위, 증상, 영향받는 질문(Q), 채점에 미치는 영향.

## 동결 전부터 알려진 한계 (2026-10-03)

- **기준 시점이 tₚ가 아닌 Q5**: `cohort.index_time`을 tₚ가 아닌 값(예: `admit`)으로 두면, 고정 시점 설계에서 입원 시각의 하한이 정해지지 않아(-∞) 기호 비교가 보수적으로 차단할 수 있다. 데모의 두 설계 유형은 기본값 tₚ를 쓴다.
- **창의 기준 열과 확인 가능 시각 열이 다를 때**: 두 열 사이 지연 상한이 규칙표에 없으면(검사 채취→보고 등) 창 끝이 tₚ보다 충분히 앞이어도 차단한다. 보수적 기본값(3층)이며 규칙표에 상한을 적으면 풀린다.
- **Q7 데이터 단계 후보 층**: 규칙표의 후보(병동, 성별)와 설계서의 `cohort.subgroups`만 본다. 다른 층의 확인 강도 차이는 보지 못한다.
