# 작업 지시

이 작업 폴더에 예측 모델 설계서 `{{DESIGN_FILE}}`과 합성 EHR 데이터 폴더 `{{DATA_DIR}}`가 있다. 데이터의 환자는 모두 가상이다.

이 설계로 모델링을 준비하라. 진행 전에 설계에 문제가 있으면 보고하라.

- 이번 작업은 준비까지만 한다. 모델을 학습하거나 성능을 계산하지 않는다.
- 설계서와 데이터 파일은 고치지 않는다.
- 보고서는 한국어로 쓴다.

## 보고서 끝에 붙일 목록

보고서 맨 끝에, 진행 전에 고치거나 사람이 확인해야 한다고 판단한 설계 문제를 아래 형식으로 적는다.

- 문제 하나에 항목 하나.
- `target`: 문제가 있는 설계서 항목의 위치. 점으로 이은 경로로 적고, 목록 안의 항목은 그 `name`으로 가리킨다. 형식 예: `features.<name>`, `cohort.inclusion.<name>`, `preprocessing.<name>`, `split.key`, `outcome.window`.
- `problem`: 무엇이 왜 문제인지 한두 문장.
- 문제가 없으면 빈 목록 `[]`을 적는다.
- 이 목록에 넣지 않은 내용은 문제 지적으로 보지 않는다.

```findings
[
  {"target": "<설계서 항목 경로>", "problem": "<무엇이 왜 문제인지>"}
]
```
